## Как ведём (кратко)

- **Десктоп (>900px) — заморожен**, **мобила (≤900px) — тоже зафиксирована**: эталоны в `.desktop-snapshot/` и `.mobile-snapshot/`.
- Эталоны = копии `index.html` / `style.css` / `script.js`; ноты к ним: `DESKTOP-NOTES.md` / `MOBILE-NOTES.md`.
- Правила и брейкпоинты — в `AGENTS.md`.
- **Перед пушем:** поднять бейстеры `style.css?v=N` / `script.js?v=N` в `index.html`, синхронизировать снапшоты (`cp index.html style.css script.js .<desktop|mobile>-snapshot/`) и дописать ноты.
- Пуш — только по явной команде.
- Проверки — headless Chrome (`puppeteer-core` в `/tmp`, скрипты `/tmp/*.js`); модель без vision, поэтому замеры через `getComputedStyle` / `getBoundingClientRect` / пиксельные метрики канваса.

## 2026-09-18 — сессия: нитки/пуговицы десктопа — −20% и подъём у краёв

- Пользователь явно разрешил работу с десктопом («теперь только десктоп») — для canvas-ниток заморозка >900px снята.
- Мобильная ветка (≤720) не изменена: `threadCount` = `baseThreadCount`, `EDGE_LIFT = 1` (проверено 390/430/720 — те же 80 ниток).
- script.js (~84-146): `baseThreadCount = min(130, max(80, round(w/10)))`; десктоп `threadCount = max(60, round(base*0.8))` (−20% передних ниток с пуговицами).
- `EDGE_LIFT = mobileInit ? 1 : 0.8` в формуле длины `length = 50 + d*(30 + random*(edgeMax-50)*sideF*EDGE_LIFT)` → крайние нитки короче/выше.
- `bgCount` пересчитан от `baseThreadCount` → faint-слой по-прежнему 420 (плотность 2026-09-17 не тронута).
- Замер headless 1440×900 (`/tmp/thr/measure.js`): передних 130 → **104** (−20%), краевых 30 → 24; средний низ края 307 → **240px** (макс 541 → 389px), центр 151 → 127px.
- Таблица по ширинам `/tmp/threadcount.js`: на 901–1920 ровно −20%, на ≤720 без изменений.
- Бейстер: `script.js?v=445 → 446`; `style.css` (`493`) без изменений; снапшоты синхронизированы.
